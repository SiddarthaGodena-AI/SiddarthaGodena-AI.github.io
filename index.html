What I shipped to production

AI Call Sentry — took manual QA out of 10,000+ support calls

Every incoming support call used to need a person to listen and score it. I built a serverless pipeline — S3 upload triggers Lambda, which calls Transcribe, which feeds a sentiment model — so it got scored the moment the call ended, with no one listening first. I didn't ship it on faith: I benchmarked the model's output against calls our team had already reviewed by hand before it went anywhere near production.

It landed at 88–92% agreement with human review — enough for my mentor to sign off on replacing manual QA for the bulk of the 10,000+ calls we were processing.

I wrote up how this one works in more detail — link in the Writing section below.

Talk-to-Data — turned 500+ hours of recordings into an instant answer

Before this, getting an answer out of a recording meant someone sitting through it. I built REST APIs that let non-technical users ask a plain-language question across 500+ hours of combined video, audio, image, and text data and get an answer back — speaker-analytics and summarization ran automatically through Vertex AI, so nobody had to watch a session first just to know what was in it.

Voice-driven multi-agent troubleshooting system — replaced guesses with grounded answers

A single general-purpose agent was handling every kind of query, regardless of domain — so answers were inconsistent. I split it into domain-specialized LLM agents routed through LangChain, and grounded every response in a FAISS-backed RAG pipeline pulling from real documents, instead of the model answering from memory alone.
